# Shortcut Cheat Sheet

## General 
| Command                           | Description                                                               |
|-----------------------------------|---------------------------------------------------------------------------|
|`Ctrl`+`Alt`+`HOME`                | Focus RDP Bar, cycle `tab` to select the minimize option                  |

## VS Code
| Command                           | Description                                                               |
|-----------------------------------|---------------------------------------------------------------------------|
| `Ctrl`+`Shift`+`E`                | GoTo `File` Explorer, pressing it again goes back to the `main window`    |
| `Ctrl`+`Shift`+`F`                | GoTo `Search` Panel                                                       |
| `Ctrl`+`'` (single quote)         | GoTo `Terminal`, pressing it again goes back to the `main window`         |
| `Ctrl`+`Shift`+`I`                | GoTo `Copilt` Panel                                                       |
| `Ctrl`+`Shift`+`P`                | GoTo `Command Bar`                                                        |
| `Ctrl`+`1-9`                      | GoTo / OpenNew `Side by Side` window                                      |
| `Ctrl`+`Shift`+`A`                | Open `Agents` Window                                                      |
