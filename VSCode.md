# Shortcut Cheat Sheet

## General
| Command                           | Description                                                               |
|-----------------------------------|---------------------------------------------------------------------------|
| `Ctrl`+`Alt`+`HOME`               | Focus RDP Bar, cycle `tab` to select the minimize option                  |

## VS Code
| Command                           | Description                                                               |
|-----------------------------------|---------------------------------------------------------------------------|
| `Ctrl`+`Shift`+`E`                | Go to `File` Explorer, pressing it again goes back to the `main window`   |
| `Ctrl`+`Shift`+`F`                | Go to `Search` Panel                                                      |
| `Ctrl`+`'` (single quote)         | Go to `Terminal`, pressing it again goes back to the `main window`        |
| `Ctrl`+`Shift`+`I`                | Go to `Copilot` Panel                                                     |
| `Ctrl`+`Shift`+`P`                | Go to `Command Bar`                                                       |
| `Ctrl`+`1-9`                      | Go to / open new `Side by Side` window                                    |
| `Ctrl`+`Shift`+`A`                | Open `Agents` Window                                                      |
